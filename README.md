# Mission: Math

Play: **https://math.daviddenton.ca**

Space-themed adaptive math practice for **Cadet Alastair**, Alberta Grade 3, on a regular iPad in landscape.

Phase 1 is playable now: custom keypad, session loop, four skills, no AI. Problems are generated by templates and graded in code.

## Skills in this build

- `NUM-AS` — addition and subtraction within 1000 (first-session focus)
- `NUM-MD` — multiplication and division within 100
- `TIM-CLK` — telling time (drag the clock hands)
- `MEA-PER` — perimeter

Alastair is at the start of Grade 3, so the first mission opens on easy no-regrouping addition/subtraction.

## Run it

On this laptop, for tinkering:

```bash
cd ~/dev/MATH
npm install
npm test
npm run dev
```

On the iPad, open Safari to:

```text
http://YOUR_MAC_LAN_IP:5173
```

Find the Mac IP with `ipconfig getifaddr en0`. Hold the iPad **landscape**. Chrome on the Mac is fine for layout checks; touch and palm-rest issues only show up on the iPad.

## Run it off the Mac Studio (recommended)

The Studio should be the always-on box. The iPad talks to it on the LAN. Alastair’s progress lives **on the iPad** (Safari / Home Screen storage), not on the Mac, so moving the server does not wipe his mastery.

**1. Copy the project once**

On this Mac:

```bash
rsync -a --exclude node_modules --exclude dist ~/dev/MATH/ studio:~/dev/MATH/
```

Use the Studio’s hostname or IP. Or drop the folder on a USB drive. Git is even better if you put the repo on GitHub/GitLab.

**2. On the Studio**

Install Node 22 LTS if it isn’t there (`brew install node`). Then:

```bash
cd ~/dev/MATH
npm install
npm run build
npm run preview -- --host --port 5173
```

`preview` serves the production build. Use that on the Studio, not `npm run dev`.

Give the Studio a stable name so the iPad URL does not change when DHCP does:

```bash
sudo scutil --set LocalHostName mathbox
sudo scutil --set HostName mathbox
```

Then on the iPad: `http://mathbox.local:5173`

**3. Keep it awake**

System Settings → Energy: prevent automatic sleeping when the display is off. On a Studio, also keep it logged in.

**4. Optional: start on login**

Save this as `~/dev/MATH/scripts/serve.sh`:

```bash
#!/bin/zsh
cd "$HOME/dev/MATH" || exit 1
/usr/local/bin/npm run preview -- --host --port 5173
```

Then add it as a Login Item, or a `launchd` plist, so a reboot still serves the app.

**5. Later (Home Screen install / Airplane Mode)**

Safari will not treat `http://` as a real installed app. When you are ready for that: `mkcert` on the Studio, trust the cert on the iPad, serve `https://mathbox.local:3443`. Tailscale is the other path if you want it to work at grandma’s house. Not required for a Safari-tab daily session.

### First-run on the iPad

1. Settings → Apps → Safari → Advanced → Web Inspector (for Mac debugging).
2. Open the URL in Safari, landscape.
3. Optional later: Share → Add to Home Screen. Phase 1 still works in a Safari tab.

Guided Access (Settings → Accessibility) will keep him in the app for the 12-minute session.

## What is not in Phase 1

Grok item generation, the parent dashboard, hangar upgrades, HTTPS / Home Screen offline, and the other 11 curriculum nodes. Those are later phases in `mission-math-build-spec.md`.
